## Lab Questions

### In plain English describe the function and use of a multiplexer.

- The function and use of a multiplexer is to be able to have multiple inputs that all lead to one output its almost like putting everything you want to input to 1 output at a time which can be selected based on input that can choose which output if multiple.

### In plain English describe the function and use of a demultiplexer.

- The function and use of a demultiplexer is the inverse of a multiplexer which in this case it takes one input to choose multiple outputs.

### What other uses might these circuits have? (Think Shannon’s)

- Other uses that these circuits might have are transmitting more information over a quicker period by saving time adding everything you want to input and allowing them to then be chosen as outputs acting as a data selector.
